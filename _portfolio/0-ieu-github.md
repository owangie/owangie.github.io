When I started, nobody in the unit used version control, and most people had never heard of GitHub. I set up the [IEU-GCF organisation](https://github.com/IEU-GCF), handled procurement of the licences, and then sat down with colleagues one on one to explain what it was and why an evaluation team would want it: a shared, versioned home for the code and data behind every report.
